| Files                                      | Origin / status                                                                                                                                                                                           |

| `docs/assets/*.png`                        | Screenshots of this recipe with synthetic demo state and the generic gift icons.                                                                                                                          |

The original event prize coupon images and gift illustrations are excluded. No image of an actual event prize is needed to run the recipe. The seven sample prizes are placeholders, not an offer to provide physical goods.

Replace any slot through `public/dumpling/appearance.json`. Keep attribution for third-party assets and confirm redistribution rights for anything you add. See [customization](customization.md).
